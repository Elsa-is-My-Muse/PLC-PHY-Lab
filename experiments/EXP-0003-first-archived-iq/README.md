## 问题

能否将短时接收保存为格式明确、设置完整、可离线复核的 IQ 文件？

## 前提与设置

先确认输入连接条件及保护链适用性。首次可在明确的低风险接收条件下做采样链检查。中心频率 10 MHz、采样率 20 MS/s、模拟带宽 20 MHz、RF 放大关闭、IF/VGA 0，拟录制 0.25 s。上述是计划值，执行后填写实值。

## 步骤

1. 检查同一 HackRF 未被其他进程占用，记录器件接线和输入端接。
2. 设置采集输出目录，运行定时 IQ 流程，保存控制台输出。
3. 预期无头 `cf32_le` 文件为 40,000,000 字节；记录实际值，差异需解释。
4. 用 `tools.capture_metadata` 创建 SHA-256 和参数记录。
5. 用 `tools.analyze_iq` 分析，保存图、统计和具体问题。
