# 测量链路、参考面与保护

目标是监听充电通信 CP–PE 上的 PLC 信号。HackRF 不直接连接 CP、PE 或市电导体，接收前端需满足实际线路的连接方式、隔离、耐压及频率要求。RF 限幅和衰减不承担电气隔离功能。

## 候选连接

```text
适用于该线路的耦合器 RF 输出
  → BNC 公／SMA 公同轴线（接头需按实物确认）
  → 限幅器的规定输入端
  → 30 dB 衰减器
  → 10 dB 衰减器（是否使用按验证结果决定）
  → SMA 母／SMA 公软线
  → HackRF ANTENNA
```

该图记录此前讨论的配置，尚未代表经过完整输入保护验证。不要将器件串直接悬挂在 HackRF 接头上。普通 SMA 与 RP-SMA 的中心触点不同，订货时应明确普通 SMA、50 Ω。

## 电平预算如何填写

在参考阻抗、匹配与参数定义一致时：

`接收端电平 dBm = 前端输出 dBm − 后续衰减 dB`

HackRF One 官方列出的最大输入为 −5 dBm。应根据最大输出与瞬态留出余量，软件增益降低不能替代外部保护。前述限幅器资料中的典型泄漏输出不能作为保证的最大值；额定输入能力也不是瞬态全条件保护承诺。

需要厂家数据或合适测量支持的字段：

| 字段 | 当前值 |
| --- | --- |
| 耦合器实物型号及使用接法 | 待确认 |
| 50 Ω 负载下最大连续 RF 输出 | 未知 |
| 输出平均值／峰值的定义与测试条件 | 未知 |
| 插拔、启动等瞬态与低频抑制 | 未知 |
| 限幅器允许输入、最大残余及尖峰 | 未完整确认 |
| 固定衰减器功率、频响和实际衰减 | 待核实实物 |
| 全链路验证结论 | 未完成 |

## 定量测量时记录什么

- 参考面设在 HackRF 口、耦合器输出还是 CP–PE；转换到其他参考面需有相应标定。
- 前端工作于线性区还是已限幅；限幅后的波形不能直接用于原始 PAPR、失真或绝对幅度分析。
- RF 放大、IF/VGA、模拟滤波带宽、采样率、端接与线缆保持可追踪。
- 未校准的数字 PSD 只报告相对数字单位；仅加回“标称 40 dB”不会自动得到真实 CP–PE 功率。
- VNA 测量只安排在明确适用的断电无源台架；记录端接、校准面及夹具／耦合网络。
