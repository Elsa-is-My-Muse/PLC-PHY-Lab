## 建议的首批实验

- [ ] 复核现有器件完整型号和说明书，确认实际耦合器宽带版本。
- [ ] 在明确安全的测试条件下归档 `hackrf_info` 和短时采样日志。
- [ ] 不连接线路时记录固定设置的接收本底；注明输入端接状态。
- [ ] 在低压、隔离台架上核对保护链输入／输出，先确认仪器量程和端接。
- [ ] 首次写入 0.25 s IQ，检查字节数、格式和接收端错误／丢样信息。
- [ ] 固定中心频率与增益，对比有通信／无通信的相对谱和时域突发。
- [ ] 运行通用 OFDM 回环，记录频偏和噪声对接收的影响。
- [ ] 阅读 [BROKENWIRE 笔记](reading/BROKENWIRE.md)，解释增益设置、压缩点、测量参考面与接收端功率的区别。

## 后续能力边界

HackRF 适合先研究分频段信号与接收链。完整 Green PHY 帧的宽带解码需要评估同时采集带宽；两次不同时间的分频段记录不能拼成同一帧。VNA、示波器、信号源目前未确认拥有，其相关实验保持待开展。不能把 SLAC 的分组衰减直接等同为 50 Ω VNA 测得的 S21，比较前需说明测量定义、频率分组和参考条件。
